# 崇德仁義總頁與照片頁設計

## 目標

整合崇德仁義總頁導覽，加入 Fortune、Blessing 與獨立照片頁入口；建立 `/photos/` 靜態照片頁，讓使用者依內容與地區篩選後持續向下瀏覽完整照片並下載原圖。

本規格只涵蓋第一階段的公開網站。管理者／副管理者登入、上傳、刪除、藏經閣內容管理與後端儲存屬第二階段，另行設計。

## 總頁整合

- 主要選單新增 `Fortune`、`Blessing`、`照片`。
- `Fortune` 連到 `/fortune/`。
- `Blessing` 連到 `/blessing/`。
- `照片` 連到 `/photos/`，取代目前只捲動到總頁照片區塊的導覽方式。
- 主視覺按鈕新增 Fortune 入口，並保留現有 Blessing 與藏經閣入口。
- 手機選單沿用現有展開／收合機制；新增連結不得造成水平溢出。

## 照片頁定位

- 網址：`/photos/`
- 選單名稱：`照片`
- 頁面主標題：`崇德仁義 照片`
- 視覺沿用總頁的深藍、墨綠、金色與米白設計語言。
- 不使用世界地圖、不使用燈箱放大，也不跳轉到每張照片的獨立頁面。

## 頁面版面

### 桌機

- 頁首使用與總頁一致的品牌與導覽。
- 左側為分類篩選區，右側為單欄照片流。
- 篩選區保持容易存取，但不得遮住頁尾或在短視窗造成內容無法操作。
- 每張照片依原始比例完整顯示，不裁切。

### 手機與平板

- 分類區移到照片流上方，以可展開／收合的原生控制呈現。
- 照片維持單欄、完整比例與可讀說明。
- 下載按鈕有足夠觸控面積，不造成水平捲動。

## 照片內容

每張照片依序呈現：

- 完整圖片。
- 標題。
- 日期；未知日期顯示 `日期未詳`。
- 簡短說明。
- 內容與地區標籤。
- `下載照片` 按鈕，下載該照片原始檔案並使用資料中指定的下載檔名。

照片不需要點擊放大。頁面持續向下排列所有符合條件的照片。

## 篩選結構

第一層：

- 仁義大仙
- 老前人
- 前人老
- 墨寶
- 地區

`仁義大仙` 的第二層：

- 佛堂
- 家人
- 眾道親
- 獨照

`地區` 的第二層為資料中出現的國家／地區，可選一個或多個。城市保留在照片資料與顯示標籤中，但第一版不建立第三層城市篩選。

## 篩選邏輯

- 所有條件皆未選取時，顯示全部照片。
- 不同第一層條件採 OR：照片符合任一選取條件即可顯示。
- 多個地區採 OR：照片位於任一選取地區即可顯示。
- 只選 `仁義大仙` 時，顯示所有標記為仁義大仙的照片。
- 選取一個或多個仁義大仙第二層條件時，仁義大仙這一組改為顯示同時具備 `仁義大仙`，且符合任一已選第二層條件的照片。
- 仁義大仙組與其他第一層條件仍採 OR。例如選取 `仁義大仙 > 佛堂` 與 `日本`，顯示「仁義大仙且為佛堂」或「地區為日本」的照片。
- 每次篩選後顯示符合條件的照片數量；沒有結果時顯示可理解的空狀態與清除篩選按鈕。

## 第一版資料模型

照片資料集中在獨立 JavaScript 模組，不將每張照片硬編碼在 HTML。每筆資料包含：

```js
{
  id: 'photo-001',
  src: 'images/sample-001.jpg',
  downloadName: '崇德仁義-示範照片-001.jpg',
  title: '示範活動照片',
  date: '2026-01-01',
  description: '示範資料，日後可由管理後台取代。',
  people: ['仁義大仙'],
  renyiCategories: ['佛堂'],
  topics: [],
  country: '臺灣',
  city: '彰化'
}
```

`people` 支援 `仁義大仙`、`老前人`、`前人老`；`topics` 支援 `墨寶`。相同照片可以同時擁有多個人物、內容與地區屬性。

第一版加入數筆本地示範資料，涵蓋人物、墨寶、仁義大仙第二層與多個地區，讓所有篩選分支均可操作。示範資料在正式照片加入後可以直接替換。

## 未來管理後台相容性

- 公開照片頁只依賴統一照片資料介面，不依賴資料實際來自本地模組或遠端 API。
- 第二階段後端需支援管理者上傳與刪除、副管理者只可上傳。
- 同一角色與內容模型未來延伸至照片、訓文、電子書及新增功能。
- 帳號、角色與權限不得放在前端 JavaScript 或 GitHub Pages 靜態檔案中。

## 無障礙與錯誤處理

- 篩選使用原生 checkbox 與清楚標籤，鍵盤可操作。
- 圖片具描述性 `alt`；純示範圖片明確標示為示範。
- 圖片載入失敗時保留標題與說明，並顯示圖片無法載入提示。
- 下載連結直接指向同源本地檔案，避免跨來源下載限制。
- 使用者偏好減少動態效果時，不加入非必要動畫。

## 驗證標準

- 總頁桌機與手機選單均可前往 Fortune、Blessing 與 `/photos/`。
- `/photos/` 在桌機、平板與手機皆無水平溢出。
- 未選條件時顯示全部示範照片。
- 每個第一層條件、仁義大仙第二層與多地區複選均符合上述 OR／組內細分規則。
- 每張照片完整顯示、不裁切，並可透過按鈕下載原圖。
- 空結果、清除篩選與圖片載入失敗皆有清楚回饋。
- 現有 Fortune、Blessing、藏經閣與總頁其他區塊不受影響。
