# 首頁外部導覽精簡設計

## 目標

將首頁頂部選單精簡為只連往其他獨立頁面的入口，移除所有只在目前首頁內捲動的錨點，降低選單擁擠並讓用途更清楚。

## 頂部選單

選單只保留以下四項，順序固定為：

1. `藏經閣`，連到現有藏經閣網址。
2. `照片`，連到 `/photos/`。
3. `求籤`，連到 `/fortune/`。
4. `仙佛詞語`，連到 `/blessing/`。

移除所有首頁內部選單項目：`首頁`、`仁義大仙`、`訓文`、`修辦歷程`、`紀念文`。品牌標誌仍可作為回到首頁頂端的入口。

## 不變範圍

- 主視覺按鈕保留完整文字，包括 `認識仁義大仙`、`進入藏經閣`、`領受仙佛慈語`、`抽取六十甲子籤`。
- 首頁內的仁義大仙、訓文、修辦歷程、照片預覽與紀念文內容全部保留。
- 手機選單沿用現有展開／收合機制。
- 不修改 Fortune、Blessing、照片頁或藏經閣內容。

## 驗證

- 桌機與手機的頂部選單只顯示四個指定入口。
- 四個文字與連結完全正確。
- 選單不含任何 `href` 以 `#` 開頭的首頁內部錨點。
- 主視覺四個按鈕仍存在。
- 頁面沒有水平溢出。
- `fortune/README.md` 不得被修改或提交。
