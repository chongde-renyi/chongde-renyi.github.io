# 六十甲子籤互動頁改版設計

## 目標
將首頁簡化為單一求籤互動：立體木質籤筒正面標示「六十甲子籤」，使用者心中默想所求後直接按「誠心求籤」。籤筒與筒內籤枝同步晃動，最後抽出一支籤，再由使用者逐次點擊擲筊，連續三個聖筊後才顯示結果。

## 首頁
- 不提供問題輸入欄、類別選單或任何表單。
- 中央呈現立體木質籤筒與多支木籤。
- 按鈕：誠心求籤 / Draw a Fortune Lot。
- 求籤時籤筒左右搖晃，筒內籤枝各自不同幅度晃動，其中一支籤升起，完成後轉入擲筊確認頁。
- 保留中文 / English 切換。

## 三聖筊確認
- 顯示抽得的籤號與干支，但在確認前不顯示籤文。
- 每一次擲筊都必須由使用者主動點擊按鈕。
- 一平一凸為聖筊；連續三聖筊後籤成立。
- 任一次出現非聖筊，本支籤不成立，提供重新求籤按鈕。

## 結果頁
依序顯示：
1. 籤號
2. 干支
3. 吉凶
4. 原始籤文
5. 完整籤意（整合該籤的白話摘要與實際提醒）
6. 解說參考
7. 事業、財運、感情、健康、出行、訴訟／爭議、家庭等分類參考

分類內容只做參考，不要求使用者事前選擇。

## 技術
純 HTML、CSS、JavaScript ES modules，無外部框架或伺服器需求，可直接放在 GitHub Pages `/fortune/`。
